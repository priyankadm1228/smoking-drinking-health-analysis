## 📌 Overview

This repository contains the Jupyter Notebook used for my peer-reviewed research paper:

**“Analyzing the Impact of Smoking and Drinking on Health Metrics in Korea: A Data-Driven Predictive Approach”**

The notebook includes:
- Data cleaning and preprocessing  
- Statistical analysis (normality tests, t-tests, correlations)  
- Logistic regression models for smoking and drinking behavior  
- ROC curves, AUC scores, and cross-validation
